# Ad and tracker blocklist for the in-app browser.
#
# Format, one rule per line:
#   example.com     block this domain and every subdomain of it
#   @@example.com   never block this domain (wins over any block rule)
#   # ...           comment
#
# Rules match on domain-label boundaries, so `doubleclick.net` blocks
# `ads.doubleclick.net` but not `notdoubleclick.net`. Bare TLDs are never matched.
#
# Only subresources are filtered. A page the user navigates to is always allowed
# through, so a blocked rule can never strand them on an error page.
